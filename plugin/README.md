# exam-notes-builder (plugin)

Builds complete, examiner-proof exam notes (LaTeX to PDF) for any course from a syllabus, textbooks and past papers, proves them complete with notes-only mock exams, checks every page visually, and produces a short Exam Core.

This folder is generated from the repository by `tools/build_plugin.py`; scripts and templates are stored as Markdown in `skills/exam-notes-builder/assets/` and unpacked by the skill. Full documentation: https://github.com/soumyadipkarforma/exam-notes-builder

## Install

```
/plugin install exam-notes-builder --marketplace soumyadipkarforma/exam-notes-builder
```
